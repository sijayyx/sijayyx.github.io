## 六、番茄鱼危机

好景不长。那年冬天，“老坛番茄鱼”的老板决定回老家养老，店铺转让。新接手的是一家连锁麻辣烫品牌。

冯坤坤站在门口，看着熟悉的招牌被拆下来，整个人像被回滚了一次数据库事务——

```sql
ROLLBACK;
-- 一切回到原点，但心情已经无法恢复
```

他沉默了很久，最后说了一句：“这比线上事故还难接受。”

接下来的两周，他试遍了公司周边所有的番茄鱼：有的番茄是番茄酱调的，有的鱼片是冷冻的，有的汤底寡淡如水。他给每家店都默默打了个分，写在一个叫`tomato_fish_rating.json` 的文件里：

---

```json
{
  "老坛番茄鱼": {
    "score": 9.8,
    "status": "已关闭",
    "comment": "此生难忘"
  },
  "某记番茄鱼": {
    "score": 4.2,
    "status": "营业中",
    "comment": "番茄是酱，鱼是冰，心是凉的"
  },
  "楼下新开酸菜鱼": {
    "score": 3.0,
    "status": "营业中",
    "comment": "它甚至不是番茄鱼"
  }
}
```

同事看他日渐消沉，劝他：“要不你试试别的？”

他摇摇头：“你不懂。这不是口味问题，这是依赖问题。”

## 七、自己动手，丰衣足食

终于有一天，冯坤坤做了一个决定：自己学做番茄鱼。

他在部门群里发了一条消息：

“从今天起，我要用工程化的方式解决吃饭问题。”

他先做需求分析：

```markdown
## 需求文档：冯坤坤的番茄鱼 v1.0

### 功能需求

- 汤底必须浓郁，番茄味突出
- 鱼片必须嫩滑，不能碎
- 酸甜比例可调

### 非功能需求

- 制作时间 < 40 分钟
- 成本 < 外卖价格
- 可重复复现（不能靠运气）
```

然后他开始写“番茄鱼代码”——也就是菜谱：

```python
class 番茄鱼:
    def __init__(self):
        self.番茄 = 3  # 个，熟透的
        self.黑鱼片 = 300  # 克
        self.姜蒜 = "适量"
        self.番茄酱 = 2  # 勺
        self.糖 = 1  # 勺
        self.盐 = "少许"

    def 腌制鱼片(self):
        self.黑鱼片 = self.黑鱼片 + "蛋清" + "淀粉" + "料酒"
        return "腌制15分钟"

    def 炒番茄(self):
        for 步骤 in ["热锅", "下油", "炒姜蒜", "下番茄", "炒出汁", "加番茄酱"]:
            print(f"执行：{步骤}")
        return "浓稠番茄汤底"

    def 煮鱼片(self):
        return "水开后下鱼片，30秒捞出，保持嫩滑"

    def 出锅(self):
        return "倒入碗中，撒葱花，完成"
```

第一次尝试，鱼片全碎了，汤底太酸。他拍照发到部门群，配文：

“v1.0 上线失败，已回滚。”

第二次，鱼片完整了，但汤太淡。他说：“这是配置问题，参数需要调优。”

第三次，终于成功了。他端着那碗番茄鱼，眼眶有点红。

## 八、番茄鱼开源计划

冯坤坤没有把菜谱藏起来。他在公司内部wiki上建了一个页面，叫 “番茄鱼开源计划” ，把菜谱、步骤、踩坑记录全部公开，还附了一个issue模板：

```markdown
## 问题反馈模板

**版本**：v1.0 / v1.1 / v2.0
**问题描述**：
**复现步骤**：
**期望结果**：
**实际结果**：
**截图**：
```

同事们纷纷跟帖，有人成功复现，有人反馈“糖放多了”，还有人提交了PR（Pull Request）——也就是改良版菜谱：

```diff
- 糖 = 1 勺
+ 糖 = 0.5 勺 + 半个洋葱提甜
```

冯坤坤认真review了每一条PR，还点了赞。

## 九、番茄鱼之夜

那年年底，部门决定办一次“番茄鱼之夜”。地点就在公司茶水间，主厨自然是冯坤坤。

他提前一天开始准备，列了一张清单：

```yaml
采购清单:
  - 黑鱼: 3条
  - 番茄: 15个
  - 番茄酱: 2瓶
  - 蛋清: 6个
  - 淀粉: 1袋
  - 葱花: 1把
  - 姜蒜: 若干
  - 啤酒: 2箱   # 非必需，但推荐
```

那天晚上，他一个人做了三大锅番茄鱼。同事们排着队盛汤，有人吃完说：“坤坤，你这手艺，转行开饭店吧。”

冯坤坤笑了笑，说：

“写代码是给别人用的，做番茄鱼是给自己和朋友的。两件事，都讲究一个‘用心’。”

有人问他：“你以后还会去外面吃番茄鱼吗？”

他想了想，说：

```python
if 外面有好的番茄鱼:
    return "会去"
else:
    return "自己做"
```

“但不管在哪吃，”他补充道，“番茄鱼永远是我的 main 函数。”

## 十、尾声：番茄鱼永流传

后来，冯坤坤的“番茄鱼开源计划”被公司其他部门的人知道了。有人照着菜谱做给家人吃，有人在评论区留言说：“谢谢，我女朋友很喜欢。”

冯坤坤看到这条评论时，正在改一个bug。他停下来，笑了笑，在代码注释里加了一行：

```python
# 代码会过时，番茄鱼不会。
```

而软件开发部的传说也升级了：

只要冯坤坤还在做番茄鱼，团队就不会散。

至于那个 tomato_fish_rating.json，冯坤坤把它改成了只读文件。里面只剩一条记录：

```json
{
  "冯坤坤的番茄鱼": {
    "score": 10.0,
    "status": "永久营业",
    "comment": "自己做的，才是最好的"
  }
}
```

从此，番茄鱼不只是一种食物，它成了一个部门的味觉记忆，一段代码之外的温暖故事。
