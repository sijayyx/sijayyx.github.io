在软件开发部，提起冯坤坤，大家首先想到的不是他那一手出神入化的重构功夫，也不是他凌晨三点还在提交代码的敬业精神，而是他那句口头禅——

> “傻吊们，
> “今天中午，谁跟我去吃番茄鱼？”

## 一、初识番茄鱼

冯坤坤第一次吃番茄鱼，是在入职后的第三周。那天他刚修完一个困扰团队两周的并发bug，心情大好，决定犒劳自己。他走进公司楼下那家不起眼的小店，点了一份招牌番茄鱼。

$$
a^2 + b^2 = c^2
$$

鱼片嫩滑，番茄酸甜，汤汁浓郁。他喝下第一口汤的时候，整个人愣住了。据他后来回忆，那一刻他脑海中浮现的不是“好吃”两个字，而是一段伪代码：

```python
def 冯坤坤的幸福感(番茄鱼):
    if 番茄鱼.汤底 == "浓郁" and 番茄鱼.鱼片 == "嫩滑":
        幸福感 = float('inf')
    else:
        幸福感 = 0
    return 幸福感
```

从那以后，番茄鱼成了他生活中不可分割的一部分。

## 二、番茄鱼驱动开发

冯坤坤有个习惯：每次遇到棘手的难题，他就会先去吃一碗番茄鱼。他说这叫“番茄鱼驱动开发”（Tomato-Fish Driven Development，简称TFDD）。

有一次，系统线上崩了，日志里全是神秘的 NullPointerException。整个部门加班到晚上九点，没人找到根因。冯坤坤站起来说：“我去吃碗番茄鱼。”

大家以为他在开玩笑。结果四十分钟后，他回来了，嘴角还带着一点番茄汤汁，坐下就开始敲键盘：

```java
// 找到问题了，这里没判空
if (user != null && user.getProfile() != null) {
    return user.getProfile().getNickname();
} else {
    return "匿名用户";
}
```

“你怎么找到的？”同事问。

“吃鱼的时候，脑子特别清醒，”他说，“番茄的酸让我想到，问题一定在某个被忽略的边界条件上。”

## 三、番茄鱼社交学

冯坤坤不仅自己吃番茄鱼，还喜欢拉人一起吃。他的逻辑是：愿意和你一起吃番茄鱼的人，才是真正能一起写代码的人。

他有一套自己的“番茄鱼面试法”。每次有新同学入职，他都会在第一天中午问一句：“吃番茄鱼吗？”

· 回答“好啊”的，他会热情地带路；
· 回答“我不太喜欢番茄”的，他会微微皱眉，但表示理解；
· 回答“番茄鱼是什么”的，他会沉默三秒，然后说：“那你需要补课。”

有一次，部门团建投票选餐厅，冯坤坤在群里发了一段代码：

```javascript
const 投票结果 = ["火锅", "烧烤", "日料", "番茄鱼", "番茄鱼", "番茄鱼"];
const 统计 = 投票结果.reduce((acc, cur) => {
    acc[cur] = (acc[cur] || 0) + 1;
    return acc;
}, {});
console.log(统计);
// { 火锅: 1, 烧烤: 1, 日料: 1, 番茄鱼: 3 }
```

“看，”他说，“群众的眼睛是雪亮的。”

其实那三票都是他自己投的。

## 四、番茄鱼的哲学

冯坤坤常说，番茄鱼里藏着软件工程的道理：

1. 番茄和鱼要分开处理——就像前端和后端，各司其职，最后再融合。
2. 汤底要慢慢熬——就像系统架构，急不得，需要时间沉淀。
3. 鱼片不能煮太久——就像代码review，火候到了就要及时出锅，否则就老了。

他甚至写过一篇内部wiki，标题叫《番茄鱼与微服务架构的异同》，开头第一句是：

“番茄鱼是一道菜，微服务是一种架构。但它们都讲究一件事：高内聚，低耦合。”

## 五、尾声

后来，公司搬了新的办公地点，楼下那家番茄鱼店没有跟过来。冯坤坤失落了整整一周。直到有一天，他在两公里外发现了一家新开的店，招牌上写着“老坛番茄鱼”。

他点了一份，喝了一口汤，眼睛亮了。

那天下午，他提交了入职以来最大的一次重构，代码注释里写着一行：

```python
# 感谢番茄鱼，让我再次相信，好的味道和好的代码，都值得等待。
```

从此，软件开发部多了一个传说：只要冯坤坤还在吃番茄鱼，系统就不会崩。

而冯坤坤自己知道，他吃的不是鱼，是一种信仰。
